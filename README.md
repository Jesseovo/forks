# Forks

集中整理三个外部开源项目：插件目录贡献、网站复刻模板和音乐 API。
各项目的源码放在独立子目录中，原提交历史、作者信息和许可证一并保留。

| 项目 | 用途 | 上游 | 许可证 |
| --- | --- | --- | --- |
| [awesome-ai-plugins](./awesome-ai-plugins) | AI 插件目录与 last30days-skill-cn 目录贡献 | [hashgraph-online/awesome-ai-plugins](https://github.com/hashgraph-online/awesome-ai-plugins) | Apache-2.0 |
| [ai-website-cloner-template](./ai-website-cloner-template) | AI 编程工具使用的网站复刻模板 | [JCodesMore/ai-website-cloner-template](https://github.com/JCodesMore/ai-website-cloner-template) | MIT |
| [netease-cloud-api](./netease-cloud-api) | PHP 网易云音乐接口 | [ZainCheung/netease-cloud-api](https://github.com/ZainCheung/netease-cloud-api) | MIT |

## 使用

进入对应子目录，按照各项目自己的 README 安装、运行或参与贡献。三个项目保持独立，不共用构建或运行环境。

## 导入记录

本次导入保留完整提交历史；没有把历史压缩为一次快照提交。每个原仓库的分支头也保存在 `source/<仓库>/<分支>` 标签下，具体提交见 [SOURCES.json](./SOURCES.json)。

`awesome-ai-plugins` 导入的是包含你本次目录贡献的 `add-last30days-skill-cn` 分支；原 `main` 分支另有来源标签。其 [上游 PR #755](https://github.com/hashgraph-online/awesome-ai-plugins/pull/755) 仍通过原 Fork 关联和更新。

GitHub 的 Fork 网络与已有 PR 仍属于原仓库。本集合仓库用于集中保存和浏览代码，原 Fork 继续保留。
